今天信息技术课老师教我们使用 FrontPage 制作网页，真的太有趣了！我学会了插入表格、设置背景颜色，还知道了 HTML 是什么。虽然现在看起来很简单，但当时觉得特别神奇。这个博客是我用记事本一行行敲出来的，虽然简陋，但是很有成就感。

## 我学会了什么

- 插入表格
- 设置背景颜色
- 了解 HTML 是什么
- 给文字加超链接

老师还给我们看了网页的源代码，原来漂亮的页面背后都是一行行的标签：

```html
<html>
  <body bgcolor="#ffffff">
    <h1>我的第一个网页</h1>
    <p>你好，世界！</p>
  </body>
</html>
```

> 同学们，如果你们也想拥有自己的个人主页，一定要学好信息技术课哦！

下面是我们用到的软件对比：

| 软件 | 用途 | 难度 |
| --- | --- | --- |
| FrontPage | 做网页 | 简单 |
| 记事本 | 写 HTML | 中等 |
| Dreamweaver | 专业做网页 | 较难 |

以后我会在这里记录我的学习和生活，也希望和大家一起进步！
